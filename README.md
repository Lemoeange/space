# 🍋 Lemorange 的个人主页

一个纯静态的**个人主页 + 小游戏合集**，托管于 GitHub Pages，无需构建、无需后端。

## 站点内容

| 页面 | 说明 |
| --- | --- |
| `index.html` | 主页：个人名片、项目 / 链接标签页、侧栏抽屉、进入过渡动画、气泡特效 |
| `lemon-game.html` | 🍋 柠檬狂奔 · 小游戏 |
| `minecraft.html` | ⛏️ 我的世界 · Web 复刻（3D 体素沙盒，见下方子项说明） |

## 项目结构

```
├── index.html          主页

├── minecraft.html      我的世界 Web 复刻

```

## 兼容目标

- **主页与柠檬狂奔（`index.html` / `lemon-game.html`）**：基线为 **iOS 16+ / Safari 16+**（桌面端同样是现代浏览器），纯静态、零依赖、零外部请求；仍然不使用 ES Module 与 WebGL。
- **我的世界（`minecraft.html`）**：**无兼容要求**，需较新浏览器，支持 **WebGL2** 与 **ES Module**。
- **设备**：主页与柠檬狂奔在桌面 / 移动端均可浏览（已适配刘海屏 / home indicator 安全区）；我的世界需**鼠标 + 键盘**（桌面端）。
- **网络**：主页与柠檬狂奔**零外部依赖**；我的世界依赖 Three.js，优先读取本地 `three.module.js`，缺失时自动回退 CDN。
- **深色模式**：主页与柠檬狂奔跟随系统 `prefers-color-scheme` 自动切换配色，游戏画面配色一并切换。

### 用到的现代特性

| 特性 | 用在哪里 |
| --- | --- |
| `prefers-color-scheme` + CSS 变量 | 两个页面的深浅色主题 |
| `env(safe-area-inset-*)` | 刘海屏与 home indicator 安全区留白 |
| `:has()` | 抽屉打开时锁住背景滚动 |
| `inert` | 抽屉收起时不可聚焦；窄屏打开抽屉时正文不可交互 |
| `aspect-ratio` + `ResizeObserver` | 游戏画布的显示尺寸（不再由 JS 计算高度） |
| `100dvh` | 游戏页在移动端地址栏收放时的高度 |
| Web Animations API | 主页气泡粒子（合成器线程执行，结束自动回收） |
| `IntersectionObserver` | 卡片滚动进入动画（JS 不可用时不隐藏内容） |
| `<picture>` + AVIF `srcset` | 开屏大图按屏幕密度取最小可用版本 |
| Canvas `roundRect()` | 游戏障碍物圆角（保留旧式回退） |
| Pointer Events | 鼠标 / 触摸 / 触控笔统一处理 |

### 开屏大图的体积

`assets/title.webp`（1600×743，182.5KB）之外另导出 AVIF 三档宽度：`title-700.avif`（51.7KB）、`title-1200.avif`（99.6KB）、`title-1600.avif`（113.4KB）。
手机竖屏约 86vw、3x 密度时浏览器取 1200 档，**首次进入少下载约 83KB**；不支持 AVIF 的浏览器回退到原 WebP。

## 维护须知

- **改主页**：编辑 `index.html`（结构、文案、卡片、侧栏都在一个文件里）。
- **改游戏**：`lemon-game.html` / `minecraft.html` 各自独立，互不影响。
- **加图片 / 字体**：放进 `assets/`，用相对路径引用（如 `assets/xxx.png`）。
- **侧栏抽屉的位置**：`index.html` 里 `<aside class="sidebar">` 刻意写在 `#page` **外面**。窄屏打开抽屉时会把 `#page` 设为 `inert` 当模态遮罩，抽屉若被放回 `#page` 内部，它自己也会一起进入 inert —— 表现就是「点抽屉里的选项完全没反应」。它本身是 `position: fixed`，写在哪儿都不影响布局。
- **字体子集化**：站点使用「黄油体」拆分出的子集字体；若需增补字形，用 `subset-font.py` 重新生成子集。
- **换开屏大图**：替换 `assets/title.webp` 后要重新导出 AVIF 变体，文件名固定为 `title-<宽度>.avif`（主页引用 700 / 1200 / 1600 三档）：

  ```python
  from PIL import Image
  src = Image.open("assets/title.webp").convert("RGBA")
  for w in (700, 1200, 1600):
      src.resize((w, round(src.height * w / src.width)), Image.LANCZOS) \
         .save(f"assets/title-{w}.avif", "AVIF", quality=63, speed=4, subsampling="4:4:4")
  ```

  文字类图片务必要 `subsampling="4:4:4"`，否则彩色笔画边缘会出现色度伪影。
- **本地预览**：双击 `start.bat`（需 Node），或 `python -m http.server 8080` 后访问 <http://localhost:8080>。
- **同步到线上**：改完后双击 `push.bat`，GitHub Pages 自动更新。

## 子项目：⛏️ 我的世界 · Web 复刻

### 特性

- **电影感光影与昼夜双向平滑软阴影**：PBR 材质（Standard）+ 暖色日光 + 冷色月光 + 半球天光 + 柔和软阴影（PCFSoftShadowMap，2048² 阴影图）。**昼夜双向无缝动态阴影**：白天由太阳投射阴影，夜晚由月亮接管投射清冷银白树影与山影（单帧只激活 1 个投影光，零额外 GPU 消耗）；阴影相机基于当前活动光源正交轴动态对齐纹素网格，彻底消除玩家移动时的阴影爬行与抖动；滤波采样半径提升至 2.4（`bias: 0.00004`, `normalBias: 0.042`, `radius: 2.4`），软阴影边缘过渡如丝般平滑自然，彻底消除阶梯锯齿、粉刺与悬空（Peter Panning）；太阳掠射角保护与地平线阴影自动平滑交接；半球光与环境光动态配比重平衡，消除竖直死黑面。**手持火把**时带动态跟随光源；走进**地下**时雾会自动平滑拉近并压暗。
- **高拟真柔和多波列菲涅尔水体**：
  - **平滑多频波浪与大基线法线计算**：平缓长波与次级柔和涟漪和谐交织，法线微分采样基线扩大至 0.65，彻底消除了微观法线晃动；
  - **柔和折射焦散网格**：水底波光光网采用连续正弦平方调制，流动柔顺剔透，无刺目高频噪点；
  - **物理菲涅尔与平缓碎浪微沫**：Schlick 物理菲涅尔反射（$F_0 = 0.025$），垂直直视碧绿通透、掠视水天一色；波峰碎浪随波高自然漫出柔白微沫；
  - **消除高光闪烁与次像素噪点**：高光指数收拢至 72 与 18，并随视距平滑衰减，远景水面告别刺目抖动与碎斑；
  - **远景雾气无缝渐隐融合**：远景水体与地平线雾气完全连续渐变，彻底消除视距边缘的水面生硬裁切缝。
- **经典体素方块云（纯净天空不雾蒙蒙）**：
  - 高空 136 格平流层漂浮着一块块经典的**体素像素方块云**；

### 依赖与加载

仅依赖 Three.js 核心库，按 **本地 `./three.module.js` → jsDelivr → unpkg → esm.sh** 依次回退加载；天空与水面是自定义着色器（暗角、水下色调是 CSS 叠层，并没有额外的后期处理通道），无官方插件。

### 存档与调试

- **存档**：世界改动、背包、工具耐久、熔炉内容存在 `localStorage`（`mc_world_v1` / `mc_inv_v1`），每 30 秒自动保存一次，关页面前也会保存。
  - 离出生点很远的地方挖的/盖的方块也会被保存：区块被卸载时会把改动交给一份"待存档快照"，重新走到那里再按存档还原（火把光源也会一并恢复）。
  - 不含水的区块不写水系数组，体积约为原来的一半；单个改动区块约 32K 字符，浏览器配额（一般 5MB）大约能放 70 多个改动区块。
- **调试接口**：用 `minecraft.html?debug=1` 打开时会暴露 `window.__mc`（`world` / `player` / `furnace` / `hotbar` / `stats()` / `setBlock()` / `getBlock()` / `teleport()` / `setLocked()` / `saveWorld()` 等），方便自动化测试和排查问题；不带 `?debug=1` 时该对象不存在。

## 子项目：🍋 柠檬狂奔

`lemon-game.html` 是一个简单的小游戏，与主页共用同一套视觉风格（黄油体字体 + 柠檬配色 + 侧栏）。

- **操作**：点击 / 触摸画面，或按 `空格`、`↑`、`回车` 让柠檬跳起来；结束后同样方式开下一局。
- **暂停**：切到其它标签页、或打开侧栏抽屉时**自动暂停**，回来点一下继续（不会因为切走而白白撞死）。
- **画布**：显示尺寸交给 CSS 的 `aspect-ratio`（宽屏 760:340，竖屏手机 4:3，给柠檬更多腾挪空间），JS 只按 `ResizeObserver` 同步后备缓冲并把设备像素比封顶在 2。
- **手感**：逻辑以固定 1/60 秒步长推进，120Hz 屏幕上速度与 60Hz 完全一致。
- **最高分**：存于 `localStorage` 的 `lemonHigh`。
