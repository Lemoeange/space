# 🍋 Lemorange 的个人主页

一个纯静态的**个人主页 + 小游戏合集**，托管于 GitHub Pages，无需构建、无需后端。

## 站点内容

| 页面 | 说明 |
| --- | --- |
| `index.html` | 主页：个人名片、项目 / 链接标签页、侧栏抽屉、进入过渡动画、气泡特效 |
| `lemon-game.html` | 🍋 柠檬狂奔 · 小游戏 |
| `minecraft.html` | ⛏️ 我的世界 · Web 复刻（3D 体素沙盒，见下方子项说明） |

## 项目结构

```
├── index.html          主页
├── lemon-game.html     柠檬狂奔
├── minecraft.html      我的世界 Web 复刻
├── assets/             图片与字体资源
├── three.module.js     Three.js 本地副本（minecraft 用）
├── server.js           本地静态服务器
├── start.bat           一键本地启动
├── push.bat            一键同步到 GitHub
├── subset-font.py      字体子集化脚本（开发用）
└── README.md           本文件
```

## 兼容目标

- **浏览器**：Chrome / Edge / Firefox / Safari 较新版本。
- **游戏（minecraft.html）**：需浏览器支持 **WebGL2** 与 **ES Module**。
- **设备**：桌面端完整可用；主页在移动端可浏览，两个游戏需**鼠标 + 键盘**。
- **网络**：主页与柠檬狂奔**零外部依赖**；我的世界依赖 Three.js，优先读取本地 `three.module.js`，缺失时自动回退 CDN。

## 依赖

| 依赖 | 版本 | 用途 | 是否必需 |
| --- | --- | --- | --- |
| Three.js | 0.160.0 | minecraft.html 的 3D 渲染 | ✅ 仅 Minecraft 需要 |
| Node.js | ≥ 18 | start.bat / server.js | ⚠️ 仅本地调试，可换 Python |
| ZCOOL 清刻黄（字体） | — | 站点标题 / 正文字体 | 已子集化内置在 `assets/` |

除 Three.js 核心库外，无任何第三方库或框架。

## 维护须知

- **改主页**：编辑 `index.html`（结构、文案、卡片、侧栏都在一个文件里）。
- **改游戏**：`lemon-game.html` / `minecraft.html` 各自独立，互不影响。
- **加图片 / 字体**：放进 `assets/`，用相对路径引用（如 `assets/xxx.png`）。
- **字体子集化**：站点使用「ZCOOL 清刻黄」子集字体；若需增补字形，用 `subset-font.py` 重新生成子集。
- **本地预览**：双击 `start.bat`（需 Node），或 `python -m http.server 8080` 后访问 <http://localhost:8080>。
- **同步到线上**：改完后双击 `push.bat`，GitHub Pages 自动更新。

### Git 同步（一次性配置）

```bash
git config user.name "你的名字"
git config user.email "你的邮箱"
git remote add origin https://github.com/Lemoeange/space.git
git push -u origin main
```

之后每次改动：双击 `push.bat` 即可（自动 `add → commit → push`）。

## 部署

纯静态站点，可托管到任意静态服务：

- **GitHub Pages**：Settings → Pages → Branch `main` / `(root)`。
- Netlify / Vercel / Cloudflare Pages、任意虚拟主机、对象存储静态托管。

## 子项目：⛏️ 我的世界 · Web 复刻

单文件（`minecraft.html`）实现的 Minecraft 风格体素沙盒。

### 特性

- **电影感光影**：PBR 材质（Standard）+ 暖色日光 + 冷色月光 + 半球天光 + 柔和软阴影（PCF）+ 顶点 AO + ACES 色调映射 + 景深雾 + 暗角。
- **昼夜循环**：白天 / 夜晚各 12 分钟（现实 1 秒 = 游戏 1 分钟，6:00–18:00 为白天），夜晚星空与月亮。
- **天气**：雨 / 雪自动切换；雨天带地面水花，雪天雪花飘落。
- **云层 / 精致水面 / 原版式洞穴 / 流动水**（水可坠落、蔓延形成瀑布）。
- **生物群系**：平原 / 森林 / 沙漠 / 雪地四类群系，配 **橡树、白桦、云杉、丛林、金合欢** 五种树木，以及**仙人掌、南瓜、蕨、睡莲、甘蔗、蘑菇**等植物，地貌随群系变化。
- **无限世界**：丘陵、山脉（雪顶）、海洋、沙滩、矿脉（煤 / 铁 / 金 / 钻石 / 红石 / 青金石 / 绿宝石 / 铜）、花草。
- **火把**（真实点光源）、**破坏粒子**。
- **掉落与拾取**：破坏方块掉落对应物品（草方块掉泥土、石头掉圆石等），物品会弹跳并吸附拾取，背包记录数量。
- **合成系统**：`E` 打开背包，用原木→木板→木棍，可合成**火把、木/石/铁镐斧锹、木/石/铁剑、熔炉**等。
- **工具分级**：木 → 石 → 铁三级工具，挖掘倍率递增（2.5× / 5× / 8×），剑可快速清理树叶与花草。
- **耐久度**：工具使用会损耗，图标带耐久条，耗尽即损坏（低沉碎裂音）。
- **熔炉冶炼**：放置熔炉后右键打开，投入矿石/原木/沙子 + 燃料（煤/木炭/木板），自动炼成**铁锭、金锭、木炭、玻璃、石头**。
- **饥饿值与食物**：饥饿条随时间消耗（疾跑更快）；树叶掉苹果、草丛掉小麦，小麦可合成面包、与南瓜合成南瓜派；右键进食，饱食回血、饥饿扣血。
- **怪物与战斗**：夜晚生成僵尸，白天燃烧自灭；僵尸会追击并攻击玩家；持剑左键挥砍（木/石/铁剑伤害递增），击杀掉落腐肉。
- **背包 + 9 格物品栏**：物品可堆叠（64 个/组）、数量显示、与物品栏交换；切换物品栏时短暂显示物品名；自动存档（localStorage）。

### 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` / 鼠标 | 移动 / 视角 |
| `空格` / `Shift` / `Ctrl` | 跳跃上浮 / 潜行下降 / 疾跑 |
| `F` / `E` | 飞行 / 背包 |
| `1`-`9` / 滚轮 | 选择物品栏格 |
| `0` / `N` | 切换昼夜 / 跳到白天 |
| 左键 / 右键 / 中键 | 破坏 / 放置 / 选取方块 |
| `Esc` | 暂停菜单 |

### 依赖与加载

仅依赖 Three.js 核心库，按 **本地 `./three.module.js` → jsDelivr → unpkg → esm.sh** 依次回退加载；天空、水面、后期均为自定义着色器，无官方插件。
