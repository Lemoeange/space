# ⛏️ Minecraft Web 复刻

一个运行在浏览器里的《我的世界》风格体素沙盒，纯前端实现，**无需构建、无需后端**。同时附带一个个人主页（`index.html`）和一个小游戏（`lemon-game.html`）。

## 目录结构

```
├── index.html        主页（站点入口，含两个游戏的入口卡片）
├── minecraft.html    ⛏️ 我的世界 Web 复刻（单文件，核心游戏）
├── lemon-game.html   柠檬狂奔小游戏
├── assets/           主页与小游戏的图片、字体资源
├── three.module.js   Three.js 本地副本（离线用）
├── server.js         Node 零依赖静态服务器
├── start.bat         双击一键本地启动
├── 说明.md            主页说明
└── subset-font.py    字体子集化脚本（开发用，可忽略）
```

## 特性

- **电影感光影**：暖色日光 + 冷色月光 + 天光半球光 + 柔和软阴影（PCF）+ 顶点 AO + ACES 色调映射 + 景深雾 + 暗角。
- **昼夜循环**：白天/夜晚各 12 分钟（现实 1 秒 = 游戏 1 分钟，6:00-18:00 为白天），动态天空（渐变 + 太阳光晕 + 霞光）、夜晚**星空与月亮**，光照/雾/水面/云层全部联动；按 `0` 快速切换昼夜，按 `N` 跳到白天。
- **背包与物品栏**：物品栏固定 9 格（`1`-`9` 选择），按 `E` 打开背包，点击物品即可放入当前物品栏格；全部方块（约 19 种）均可取用。
- **云层**：高空漂移的柔和云朵，随昼夜变亮变暗。
- **精致材质**：16×16 程序化像素纹理（草皮、泥土、石头、圆石、沙、沙砾、原木、树叶、木板、基岩、雪、4 种矿石、玻璃、石砖、苔石、红砖、砂岩、石英等），带颜色抖动与细节。
- **精致水面**：自定义着色器 —— 正弦波法线扰动、菲涅尔反射、天空渐变反射、太阳高光；海洋/湖泊只渲染**连续顶面**，无区块接缝。
- **原版洞穴系统**：3D 分形噪声蠕虫状隧道 + 大空洞，越深越密集，与地表连通。
- **流动水**：单元格自动机 —— 水向下坠落、水平蔓延逐级衰减，可形成瀑布与积水。
- **无限世界**：区块流式生成/重建/卸载；平原、丘陵、山脉（雪顶）、海洋、沙滩、森林、矿脉（煤/铁/金/钻石）、花草。
- **火把**：可放置的自发光光源（带点光源，照亮周围，夜晚/洞穴有用）。
- **破坏粒子**：破坏/放置方块时飞出对应颜色的碎块粒子。
- **交互**：第一人称移动、跳跃/疾跑/潜行、飞行、游泳、破坏/放置/选取方块、热键栏、开始菜单与暂停菜单。

## 运行

**在线**：直接把本目录部署到任意静态托管（见下方「部署」）。

**本地（离线 / 一键）**：

1. （首次）下载 `three.module.js` 放到本目录（链接见下，文件名保持 `three.module.js`）。
2. 双击 `start.bat`，浏览器自动打开主页，点「项目」卡片进入游戏。

> 没有 Node.js 时，可改用命令行 `python -m http.server 8080`，再访问 <http://localhost:8080>。

### three.js 下载链接（任选其一，同一份文件）

- <https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js>（推荐，国内一般可访问）
- <https://unpkg.com/three@0.160.0/build/three.module.js>
- <https://esm.sh/three@0.160.0>

## 依赖

这是**零构建、零后端**的静态站点，依赖极简：

| 依赖 | 版本 | 用途 | 是否必需 |
| --- | --- | --- | --- |
| **three.js** | 0.160.0 | 3D 渲染引擎 | ✅ 必需（唯一运行时依赖） |
| Node.js | ≥ 18 | 本地一键启动 `start.bat` | ⚠️ 仅本地离线用，可换 Python |
| Python | 任意 | 本地静态服务器替代方案 | ⚠️ 可选 |

- 除了 **three.js 核心库**，没有任何第三方库或插件（EffectComposer / Sky 等官方 addons 均未使用，天空、水面、后期均为自定义着色器）。
- `minecraft.html` 通过动态 `import()` 按顺序回退加载 three.js：**本地 `./three.module.js` → jsDelivr → unpkg → esm.sh**。放一份本地副本即可完全离线；不放则自动走 CDN。
- 浏览器要求：支持 **WebGL2** 和 **ES Module**（Chrome / Edge / Firefox 较新版本均可）。

## 部署到线上（静态托管）

- **GitHub Pages**：推送仓库 → Settings → Pages → 选分支根目录 → Save。
- **Netlify / Vercel / Cloudflare Pages**：拖拽文件夹或关联仓库即可。
- **任意虚拟主机 / 对象存储**（阿里云 OSS、腾讯云 COS 静态网站托管）：上传文件即可。

需要上传：`index.html`、`minecraft.html`、`lemon-game.html`、`assets/`、`three.module.js`。其余（`server.js`、`start.bat`、`README.md`、`说明.md`、`subset-font.py`）仅本地用，可不上传。

## 技术说明

- 渲染：`three@0.160`，动态 `import()` 多 CDN 回退；世界按 16×16×96 区块面剔除 + 顶点 AO 烘焙到顶点色。
- 地形/洞穴/矿脉/纹理全部由种子化 PRNG 生成，结果可复现；世界高度 96，海平面 34。
- 水/火把/花草为独立网格层（opaque / cutout / water / torch），透明物体正确参与面剔除与 AO。
