# 🍋 Lemorange 的个人主页与 Web 游戏空间

一个纯静态、零构建、零后端的**个人主页与沉浸式 Web 3D 游戏合集**，可直接本地双击运行或一键托管于 GitHub Pages。

---

## 📂 站点内容与文件结构

| 页面 | 说明 | 运行依赖 |
| --- | --- | --- |
| `index.html` | **个人主页**：名片、项目/链接抽屉、平滑过渡动画、纯 CSS 气泡光效与响应式深浅色主题 | 零外部依赖（纯原生 HTML/CSS/JS） |
| `lemon-game.html` | **🍋 柠檬狂奔**：轻量休闲横版跳跃小游戏，支持触屏与键盘、自适应 DPR 与断点 | 零外部依赖（Canvas 2D） |

## 🎮 子项目：⛏️ 我的世界 · Web 复刻（Minecraft Web Edition）

单文件构建、原汁原味还原的 3D 体素沙盒世界，深度融合电影级光影、原版物理、完整村庄突袭生态、骑马驯兽、经验升级与工具武器系统。

### ✨ 核心视觉与渲染特性

1. **零阻塞离线启动架构（Bulletproof Offline Loading）**：
   - 彻底解决浏览器 `file:///` 协议下 ES 模块 CORS 限制与国内 CDN 访问超时问题；
   - 优先通过本地 `three.global.js` 同步毫秒级冷启动，同时内嵌国内极速镜像（npmmirror、知乎 unpkg、cloudflare、jsdelivr）并配置 2.5 秒 Promise.race 竞速超时熔断，杜绝卡在“正在加载引擎”；
2. **电影感光影与昼夜双向平滑软阴影**：
   - 基于 Three.js Standard 物理渲染（PBR），配备 2048² PCFSoftShadowMap 超高精度柔和阴影；
   - **昼夜双向无缝动态阴影**：白昼太阳投射温暖斜阳，黑夜月亮接管投射清冷银白树影与山峰轮廓，单帧仅激活单个投影光源，性能极佳；
   - 阴影相机基于当前视线正交轴动态对齐纹素网格，彻底根除玩家走动时的边缘抖动与阴影爬行；地平线掠射角防失真过渡与环境天光动态配比重平衡，消除竖直死黑面；
   - 手持火把自带动态空间跟随漫反射光源；步入地底深邃洞穴时，迷雾自动平滑聚拢拉近，渲染压抑的探险氛围；
3. **高拟真多波列菲涅尔水体**：
   - 连续正弦平方波微分计算法线，消除微观法线高频晃动；
   - 柔和折射焦散动态网格与 Schlick 物理菲涅尔反射（垂直俯视清澈见底，掠角倒映云影天光）；
   - 水底与深水区视距边缘雾气平滑融合，告别传统 WebGL 水面的生硬裁切边缘；
4. **经典轻盈体素像素方块云**：
   - 高空 138 格平流层漂浮着 6 种不同变种形态的体素积云群落，云体带轻微半透明微光（`opacity: 0.88`）；
   - 日出与薄暮时分被晚霞染成温润的金橙色，夜晚随月色化作幽蓝银灰；
5. **穿墙透视高亮发光边框（Glowing Wall-Penetration Silhouette）**：
   - 击中光灵箭或触发特殊状态时，目标实体激活穿墙高亮发光边框效果；
   - 采用穿透深度测试（`depthTest: false`, `renderOrder: 9999`）与独立几何线框，即便隔着千重岩层依然能清晰侦测怪物的骨骼动作与潜行动向。

### 🐾 生物与伙伴系统（Mobs & Wildlife）

#### 1. 🐕 狼与忠诚猎犬（Wolf & Dog Companion）
- 自然漫步在森林与村落周边；
- **骨头驯化**：手持骨头（`B.BONE`）右键野生灰狼可驯服为忠诚猎犬，脖颈佩戴鲜艳红项圈；
- **生命值动态尾巴**：猎犬尾巴翘起角度实时反映当前血量，满血傲然高翘，受伤低垂；
- **疗伤与喂食**：手持肉类（生肉、熟肉、腐肉）右键可为猎犬回复生命；
- **指令切换**：空手右键随时切换**坐下待命（Sit）**与**起身巡逻（Stand）**；
- **协同作战（Pack Combat）**：当玩家挥剑攻击或拉弓命中任何敌对生物时，跟随的猎犬将爆发狂吠疾驰扑咬目标，造成高额撕咬伤害！

#### 2. 🐎 骏马驯服与策马疾驰（Horse Riding）
- 拥有骏马专用长颈、鬃毛、马蹄与长尾模型，支持红棕、象牙白、黑炭等多种天然毛色；
- **驯服机制**：空手右键多次跨上野马可驯化，喂食小麦或苹果可显著加速驯服好感；
- **装备马鞍**：驯化后手持马鞍（`B.SADDLE`）右键即可完成装鞍；
- **高速疾驰骑乘**：
  - **[W A S D] 策马奔腾**：奔跑时速高达 **7.8 m/s**，伴随节律强劲的沉稳马蹄声（`playGallop`）；
  - **[空格] 腾跃跨栏**：一跃腾空 1.3 格，轻松跨越栅栏与陡峭坎坡；
  - **[Shift] 飘逸下马**：随时按 Shift 键平稳跳下马背。

#### 3. 🐈 猫咪与好帮手（Cats）
- 拥有姜黄猫、三花猫、燕尾服猫 3 种花色；
- **防浮空与真实步态**：重构四足对角同步爬行步态（前左+后右协同），身姿随步伐轻微起伏，尾巴自然摇曳，彻底根除浮空移动；
- **驱逐苦力怕**：猫咪会主动惊退周围的苦力怕，让苦力怕落荒而逃，是家园的守护神；
- **清晨献礼**：每天清晨猫咪会从原野带回线、羽毛、生鱼等战利品赠予玩家。

  - **双通道穿戴交互**：手持防具右键一键穿戴（伴随清脆金属碰撞音效与火花），也可在背包（`E` 键）全新防具栏中自由点击穿脱；
  - **经典工作台合成配方**：5 铁锭/钻石合成对应头盔，8 铁锭/钻石合成对应胸甲；
- **🥛 铁桶挤牛奶与状态净化（Milking & Cleansing）**：
  - 手持空铁桶对准奶牛右键，伴随温柔哞叫声挤出新鲜【牛奶桶】；
  - 右键畅饮牛奶，伴随咕嘟饮水音效，瞬间清空身上的所有负面状态（包括不祥之兆 Bad Omen、减速与虚弱等），恢复 1 格饱食度并返还空铁桶；
- **💛 金苹果神圣吸收心（Absorption Hearts）**：
  - 享用金苹果时，除了饱食度补满与强力生命恢复外，额外激活 **2 颗闪耀吸收金心（💛，4 点护盾生命）**；
  - 受到敌对生物攻击或摔落伤害时，吸收金心将优先抵扣消耗，完美还原 Minecraft 经典吸收护盾体验；
- **🔥 打火石引火与烈焰火花**：
  - 手持打火石右键方块可擦出清脆金属燧石脆响与烈焰火花粒子，右键 TNT 瞬间引燃引信进入爆炸倒计时；
- **✨ 创造模式与完全静音飞天（Creative Mode）**：
  - 按 **F** 键一键切换**创造模式**与生存模式；创造模式下免疫一切伤害，可随心所欲高空自由飞翔；
  - **完全静音机制**：飞行状态下绝对不发出任何走路或落地声响；同时移除了其他所有生物的走路杂音，只保留自然环境与玩家真实互动的音效；
- **🛡️ 铁盾牌防御**：手持盾牌右键可举盾格挡并完全吸收怪物攻击伤害；
- **🌟 不死图腾（Totem of Undying）**：置于背包中，当受到致命伤害时自动触发涅槃护体，爆发全屏金绿光芒并立即回血免除死亡；
- **🎣 钓鱼系统**：手持鱼竿抛入水池，观察浮标涟漪收杆即可钓获生鱼与深水宝藏；
- **🔮 末影珍珠**：右键抛掷瞬移至目标落点；
- **🔭 望远镜**：按住 `V` 键平滑推进长焦缩放视野。

## 🚀 本地运行与部署

### 1. 本地极速运行
- **推荐方式**：双击运行目录下的 `start.bat`，脚本将自动启动内置的 `server.js` 静态服务器并使用默认浏览器打开 <http://localhost:8080>；
- **纯离线直接打开**：双击 `minecraft.html` 亦可依靠内置的 `three.global.js` 本地直接加载畅玩。

### 2. 同步到 GitHub Pages
修改代码后直接双击根目录下的 `push.bat`，即可一键自动执行 `git add .`、`git commit` 以及远程 `push` 推送到 GitHub 仓库。
